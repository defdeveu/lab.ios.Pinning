# iOS Pinning lab

Open `lab.ios.Pinning.xcodeproj` with Xcode 27 or newer. The project targets iOS 17 and uses Swift 6.

The trainer will provide the exercise instructions, server environment, and expected outcomes. Hosted endpoint values are supplied through `Config/Hosted.xcconfig`; `Config/Local.example.xcconfig` is a template for trainer-led local sessions.
